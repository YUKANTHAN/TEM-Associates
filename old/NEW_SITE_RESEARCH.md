## Cross-Site Synthesis: Patterns for TEM

### Navigation patterns
| Pattern | Used by | TEM recommendation |
|---|---|---|
| Top-level: Home / Projects / Services / Expertise / About / Contact | Arup, HOK, SOM, Jacobs | ✅ Adopt (already planned) |
| Mega-dropdown with embedded featured content | Jacobs, AECOM, WSP, SP | Use for Services + Projects only |
| Numbered nav items (01-10) | Kalpataru | Skip (too corporate-RE) |
| Country selector gate | Skanska, CBRE | Skip (TEM is India-local) |
| Single-line always-visible nav | RV Construction | ✅ Mobile pattern |

### Hero patterns

|---|---|---|
| Full-bleed image + headline + CTA | Most | ✅ Adopt (project_highway_railway.jpeg) |
| Stat counters under hero | Jacobs, WSP, SOBHA, Kalpataru | ✅ Adopt (15+ yrs, 33 staff, 66% advanced degrees) |

### Content section patterns
| Pattern | Used by | TEM screen fit |
|---|---|---|
| Capability cards (image+label, no body) | Fluor, Lendlease, WSP | Services screen |
| Market/sector cards with 1-line blurbs | DPR, Bouygues, ZHA | Verticals screen |
| Values as full homepage sections | DPR | Core Values (within About/MD screen) |
| Employee portraits + quotes | Arup, SOM | MD/Org screen |
| Named contacts with photos/emails | HOCHTIEF | Contact screen |
| Interactive timeline | SP, Hochtief | Track Record or JVs screen |
| Process/behind-the-scenes imagery | RV Construction | Mobilization screen |
| Stage-based service listing | RV Construction (01-07) | Capabilities screen |
| Stats block with big numbers | Kalpataru, Jacobs, WSP | Hero + Capabilities |
| News/press list with dates | Most big firms | Skip (TEM has no newsroom) |
| Content type labels (Article/Brief/Report) | CBRE | Skip |
| Region tags on projects | Jacobs, WSP | Use for sector tags |

### Element placement rules derived
1. **Logo top-left, nav top-right** — universal (except SP which centers logo)
2. **CTA buttons verb+object** — "Book a site visit" (RV), "Explore our work" (SP), "See our projects" (Arup), "View Projects" (DPR) — matches DESIGN_RULES
3. **Phone number visible early** — RV shows 3×, Kalpataru in sticky bar, Bouygues in contact — TEM should show +91 8220075006 in hero + contact
4. **Stats near hero** — before scroll — TEM: 15+ years, 33 staff, 5 sectors, 66% advanced degrees
5. **Project images with location/sector tags** — Jacobs, WSP, Hochtief — TEM: Chennai Bypass, Salem, Moradabad, DFC, KLIS, Abu Dhabi, Vikravandi
6. **Footer = address + phone + email + nav repeat + legal** — universal — TEM: Sriram Complex address + .example email (per rules)
7. **No testimonials/logos walls** — none of the 21 show client logo walls on homepage (SP shows client names in prose only) — matches DESIGN_RULES no-invented-testimonials

### What TEM should NOT copy
- Skanska's country gate (overkill)
- Kalpataru/SOBHA's 15+ slide carousels (excessive; rule 3 waiver allows 13 screens but each screen should be one section)
- AECOM's mixed content-type grid (confusing hierarchy)
- HOCHTIEF's investor-relations-heavy homepage (TEM is not publicly traded)
- CBRE's newsletter capture (no list to build yet)
- SP's deep mega-menus (too many companies; TEM has 5 sectors + PMC)

### Recommended TEM nav (final)
`Home | Projects | Services | Expertise | About | Contact`
- **Home** → Hero + Visit (stats) + Capabilities preview
- **Projects** → Track Record (3 photo-chapters) + Mobilization
- **Services** → Services + Verticals
- **Expertise** → Capabilities + R&D/Trikaal
- **About** → MD/Org + JVs/Clients + Core Values
- **Contact** → Contact screen
