## 11. Cross-Company Pattern Library (Recurring Design Decisions)

### Color strategies
- **Single reserved accent**: Stripe (purple), Sanity (coral-red), Oracle (red wordmark only), Ferrari (red sparingly)
- **Dark-first**: Vercel, Linear, Sentry, Supabase, Warp, Cursor — developer/AI audiences
- **Warm minimalism**: Notion, Starbucks, Mastercard — cream/soft surfaces
- **Brand color as urgency**: Binance Yellow, Vodafone Red, Al Jazeera orange/red

### Typography strategies
- **Massive display + tight body**: Nike (Futura uppercase), Tesla (Universal Sans), Vodafone (monumental uppercase)
- **Editorial serif**: Notion, WIRED, The Verge, Oura
- **Monospace/technical**: Ollama, Warp, Resend, Sanity (IBM Plex Mono eyebrows)
- **Custom proprietary**: Figma, Lamborghini (LamboType), Renault (NouvelR), Starbucks (SoDoSans)

### Layout strategies
- **Full-bleed cinematic hero**: Tesla, SpaceX, Apple, Runway
- **Masonry/image-first grid**: Pinterest, Al Jazeera density
- **Three-surface channel**: PlayStation
- **Radical subtraction**: Tesla (minimal to extreme)
- **One section per screen** (aligned with tasteskill rule 3): common across premium sites

### Component strategies
- **Pill buttons**: Jobright (black), Runway (pure black), Mastercard (orbital pills), NerdWallet (near-square corners)
- **Gradient accents**: Cohere, Runway, Raycast, Stripe, Revolut, Renault (aurora)
- **Dark hero + light reading band**: Runway (cinematic dark hero, paper-white reading bands)

## 12. Applicability to TEM Associates (filtered through DESIGN_RULES.md)

TEM Associates constraints (from DESIGN_RULES.md):
- Kind: service; site-kind: other → **No shader effects, no gradients as decoration, no dark heroes, no loops. Photographs lead.**
- Radius: soft. Never violet/lavender.
- One section per screen; equal edges; no captions under images.
- One dealt moment (photo- or type-led).
- Address: street + district only; contacts on `.example`.

### Patterns TEM Associates CAN adopt (compatible with rules)

| Pattern | Source | How TEM Associates applies it |
|---------|--------|-------------------------------|
| Photograph-led hero | Tesla, Apple, Runway, Airbnb, Nike | Hero is a real construction/industrial photograph, enters once on load |
| Full-bleed cinematic imagery | Tesla, SpaceX, Apple | Full-width site photo of industrial facility or project |
| One section per screen | tasteskill + premium sites | Hero, visit block, offer, about, booking each on own screen |
| Equal left/right edges | tasteskill rule 4 | `.wrap` constrains content symmetrically |
| Soft radius | tasteskill | `radius: soft` (not sharp fintech, not round consumer) |
| Serif/editorial headings | Notion, WIRED, The Verge, Oura | Serif display for h1/h2, clean sans body |
| Warm neutral palette | Starbucks, Mastercard, Notion | Cream/soft surfaces, earth tones — construction-appropriate |
| Pill/soft buttons | Jobright, Runway, Mastercard | Soft pill buttons with solid fill, no gradient |
| Stats counter (hard fact) | Jevelin Architect, Jevelin Construction | "22 years of scheduled delivery" as one hard fact on first screen |
| Team headshot grid | Jevelin Architect | Real team photo in About section |
| Category tags on projects | Jevelin Architect | Service category labels on offer cards |

### Patterns TEM Associates MUST NOT adopt (conflict with rules)

| Pattern | Source | Conflict |
|---------|--------|----------|
| Dark hero / dark theme | Vercel, Linear, Sentry, Runway, Warp | tasteskill: dark heroes are tech-only; TEM is "other" |
| Gradients as decoration | Stripe, Cohere, Renault, Revolut | tasteskill: no gradients on "other" kind |
| Violet/lavender accent | Mistral, Kraken, Linear, Mercury | tasteskill Never: no violet/lavender |
| Neon accents | Minimax, Shopify | Not construction-appropriate; avoid |
| Client logo strip | Jevelin Construction | tasteskill Never: no invented clients/logos |
| Invented testimonials/reviews | Jevelin Construction | tasteskill Never: no invented quotes |
| Masonry grid | Pinterest, Jevelin Construction | Could violate one-section-per-screen if overused |
| Top contact bar | Jevelin Construction | tasteskill rule 9: footer contact only, street+district |
| Chat widget / conversational UI | Intercom | Not required; adds clutter |
| Motion-heavy hero slider | Jevelin Construction | tasteskill: hero enters once on load (`data-enter`), no loops |

## 13. Recommended Design Direction for TEM Associates

Synthesizing awesome-design.md patterns with DESIGN_RULES.md:

- **Atmosphere**: Warm minimalism + editorial photography (Notion + Apple + Tesla)
- **Palette**: Cream/soft surfaces with earth-tone accent (terracotta/brown like Claude, or olive/construction-earth), never violet
- **Typography**: Serif display headings (WIRED/The Verge) + clean sans body, `text-wrap: balance`, line length < 80 chars
- **Hero**: Full-width construction photograph, enters once on load, main button inside hero
- **Sections**: Hero → Visit block → Offer (3 cards) → About (team photo) → Booking (form), one per screen
- **Buttons**: Soft pill, solid fill, hover step 2px (tasteskill rule 5)
- **Accent**: Single reserved accent color (terracotta/brown), used sparingly like Ferrari red or Sanity coral
- **Stats**: "22 years of scheduled delivery" hard fact on first screen
